# Laura Portfolio Frontend

Portfolio de **Laura Santillan** — Data Engineer.

Mismo motor que `portfolio-frontend` (Lucas), con paleta y elementos propios:
- Pink + teal + amber
- Grid de datos + dots flotantes (vs estrellas)
- Tipografía Georgia para el nombre
- Iconos `Database`, `BarChart3`, `Sparkles` (vs `Rocket`)
- Konami → ✨
- Favicon 📊

## URLs prod
- Frontend: https://laura.santillan.pro
- Backend: https://backend.santillan.pro

## Variables
- `NEXT_PUBLIC_API_URL` → URL pública del backend (browser)
- `INTERNAL_API_URL` → URL interna Docker para SSR

## Login oculto
- Desktop: Konami code (↑↑↓↓←→←→BA)
- Mobile: 5 taps en esquina superior derecha
