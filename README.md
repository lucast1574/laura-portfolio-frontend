# Laura Portfolio Frontend

Portfolio de Laura Santillan (Data Engineer). Mismo motor que el de Lucas, paleta y elementos visuales orientados a data.

- Next.js 14 + Tailwind + Framer Motion
- Estética: pink+teal+amber, grid de datos de fondo, barras animadas
- Login oculto via Konami (↑↑↓↓←→←→BA) o 5 taps esquina superior derecha en mobile
- i18n es/en por header
